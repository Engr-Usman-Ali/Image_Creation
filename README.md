# 🖼️ AI Image Generation & Upscaling Tool  

A Streamlit app for creating AI-generated images using **Stable Diffusion**.  
Users can:  
- Generate images from text prompts  
- Regenerate or modify recent images  
- View history gallery of generated images  
- Upload images and upscale (increase resolution)  

---

## 🚀 Features
- **Text-to-Image**: Create unique AI images from your own prompt  
- **Modify/Regenerate**: Improve or change previous generations  
- **Upscale**: Upload or use last generated image to enhance quality  
- **History Gallery**: See all generated images in one place
